# 架构术语学习通 · 小程序原生版（archgo-mp）

个人主体的微信小程序，内容与 `archgo-public`（Web 纯净版）一致：**自著术语概念卡片学习 + 术语自测**。不含任何历年真题 / 教材考点等第三方版权内容，免费、无支付。

> 工程现状：**全部 6 页面 + 共享组件 + 图标已完成并通过自动化验证**（65 项功能测试 + 27 项静态检查全过）。等备案号下来即可提审；考后联调见文末「真机联调清单」。

## 为什么是原生而不是 web-view 套壳

微信官方文档明确：web-view 组件**「个人类型的小程序暂不支持使用」**，且需企业主体 + 已备案域名配置业务域名。原生开发无主体与备案门槛，是个人号唯一可行路线。

## 关键决策（已执行）

1. **登录/同步**：取消 Web 版的账号门禁，一期纯本地（wx.Storage）。账号页保留「微信一键登录」入口（toast 提示考后开放），二期 `wx.login` + 微信云开发做多端同步。
2. **BGM / 音效**：一期砍掉（Web Audio 实时合成小程序不支持）。
3. **类目**：「工具 → 信息查询」，名称/简介避开「培训、课程、考试、通关」等字眼。
4. **倒计时**：原逻辑保留（2026-10-24 09:00，考前 urgent 红显，考后自动降级「已考完」态）。
5. **account 页不在 tabBar**：tabBar 5 项（学习/词库/自测/统计/设置），账号页从设置页进入——**当前版本未放入口**，可从学习页空态或分享进入；联调时如需常驻入口，在设置页「关于」加跳转即可。
6. **浅色主题**：app.wxss 加 `.theme-light` 变量覆盖，页面根视图 `class="page theme-{{theme}}"`，各页 onShow 经 `C.syncTheme` 同步；canvas 图表色由 JS 按主题单独取色。

### 小程序备案（提审前置，2023-09 起未备案不得上架）

前提：先注册小程序账号拿到 AppID（未注册时按下面「第 0 步」走）。

**第 0 步 · 注册小程序账号**（约 10 分钟，免费）：
[mp.weixin.qq.com](https://mp.weixin.qq.com/) → 立即注册 → 选「小程序」→ 填**未注册过微信生态（公众号/开放平台/企业号/个人号）的新邮箱** + 密码 → 邮箱激活 → 主体类型选「**个人**」→ 填身份证信息 + 管理员手机号 → **管理员本人微信扫码**实名 → 确认（主体类型提交后不可变更）。完成后 AppID 在 开发 → 开发设置 → 开发者ID。个人主体免认证（300 元认证可选，不影响开发与发布）。

入口：mp.weixin.qq.com → 首页「小程序需补充备案信息 → 去备案」，或 设置 → 小程序备案。**不需要域名和服务器**，与网站 ICP 备案是两个体系。个人主体免费。

材料（个人）：身份证正反面彩色扫描件（JPG/PNG，≤200KB，分辨率 ≥1500×1100）；主体负责人与小程序负责人可为同一人（同一人只验证本人手机短信 + 一次人脸核身）；应急联系人手机号须与负责人不同号；手机号均需实名且与身份证一致。

流程与时长：

1. 填主体信息（个人 / 证件 / 通信地址）→ 填小程序信息（服务标识前置审批项选**否**，备注写「架构术语记忆与自测工具」）→ 填负责人信息 + 人脸核身
2. 平台初审：1–2 个工作日（保持电话畅通，可能来电核验）
3. 工信部短信核验：收到 12381 短信后 **24 小时内**登录 beian.miit.gov.cn 填验证码（过期被驳回需重新提交）
4. 通管局审核：1–20 个工作日，通过后下发小程序备案号（微信自动展示在小程序资料页，无需自己开发）

节奏建议：**考后立即提交，与真机联调并行**——审核期不影响开发者工具上传和体验版测试，只要提审上线前拿到备案号即可。

常见驳回原因：证件照模糊/缺角、备案信息与实名信息不一致、手机号未实名或两人同号、备注为空或描述不规范。

## 已知注意点

- **save() 防抖已配 flush**：`app.js` 的 `onAppHide` 调 `Store.flush()`，切后台/结束前立即落盘，消除 120ms 防抖窗口丢数据风险。
